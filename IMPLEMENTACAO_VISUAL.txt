┌──────────────────────────────────────────────────────────────────────────────┐
│  📈 FLUXO DE UMA REQUISIÇÃO                                                  │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  Cliente ──POST /chat──> FastAPI Backend                                    │
│                             │                                               │
│                             ├─> Detectar Skill (detectar_e_processar)      │
│                             │   ├─ "resuma" → skill_resumir()             │
│                             │   ├─ "traduza" → skill_traduzir()           │
│                             │   └─ Sem match → Processamento normal        │
│                             │                                               │
│                             ├─> AssistantBrain.processar()                │
│                             │   ├─ Prepara prompt                          │
│                             │   ├─ Chama Gemini API                       │
│                             │   ├─ Extrai tokens (entrada + saída)        │
│                             │   └─ Atualiza histórico                      │
│                             │                                               │
│                             ├─> Gerenciar Sessão                           │
│                             │   ├─ Cria/recupera session_id                │
│                             │   ├─ Adiciona ao histórico                   │
│                             │   └─ Salva timestamps                        │
│                             │                                               │
│                             └─> Retorna JSON com resposta + metadados      │
│                                    │                                        │
│  Cliente <──Response JSON──────────┘                                        │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
